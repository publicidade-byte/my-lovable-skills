# Lovable skills catalog

**57 production-ready skills** for [Lovable](https://lovable.dev). Each folder contains a `SKILL.md` (and sometimes `examples.md`) you can import from GitHub or upload as a ZIP.

Import URL pattern:

```text
https://github.com/YOUR_ORG/lovable-skills/tree/main/skills/<skill-name>
```

See the [root README](../README.md) for full overview, starter packs, and FAQs.
